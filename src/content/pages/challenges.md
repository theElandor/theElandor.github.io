## Yet Another Python Challenge

This is a challenge that I created for high school students to teach them programming and problem solving. It takes inspiration from other challenges like [Advent of Code](https://adventofcode.com/) or [The Python challenge](http://www.pythonchallenge.com/). I strongly believe that having fun in competing in these events is a great way to learn new stuff. Enjoy!
